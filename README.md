# Saint Look

Цифровой гардероб и сохранённые луки из настоящих вещей.

## Текущий этап: проработка и планирование

По запросу пользователя реализации iOS, backend, тестов и Mac bridge scripts удалены. Приложения и исполняемого сервиса в рабочем дереве сейчас нет. Старые результаты тестов — история, не проверка текущего продукта.

Подтверждено: native iOS; добавление только по фото; асинхронная AI-обработка при добавлении; 2D-вырезка + признаки + вектор; предварительный подбор; быстрый локальный гардероб; необязательные пользовательские метки. Данных и production нет, legacy-миграции не нужны. Магазин — позже.
