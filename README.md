# Saint Look

Цифровой гардероб и сохранённые луки из настоящих вещей.

## Добавление вещей: #2–#4

В `backend/` и `client-ios/` реализован путь фото → ожидание → карточка → локальное чтение без сети. Несколько офлайн-добавлений сохраняются между запусками; отправка автоматически продолжается в открытом приложении после восстановления связи. Backend хранит этапы обработки и не повторяет внешний запрос с неизвестным исходом.

Режим `demo` возвращает явно обозначенный синтетический результат. Для `live` добавлены адаптеры Gemini и Photoroom; реальные аккаунты и качество ещё не проверены. Перед настоящими вызовами требуются ключи и подтверждение проверки бесплатных квот, доступности аккаунтов и opt-out Photoroom. Автоматического перехода на платный тариф или подмены ошибочного live-результата demo нет.

Запуск: [backend](backend/README.md), [iOS](client-ios/README.md), [общий API](docs/api/local-ingestion.md). Подробности: [провайдеры](docs/api/provider-integration.md), [офлайн-восстановление](docs/offline-ingestion.md). Редактирование, удаление, сроки хранения, deployment и проба реальных API относятся к следующим задачам. Ручная проверка PhotosPicker отложена пользователем.

Проверки на PR описаны в `.github/workflows/ci.yml`: Linux HTTP-тесты и macOS Simulator с настоящим локальным backend. Репозиторий публичный; используемые стандартные `ubuntu-latest` и `macos-26` бесплатны. Если репозиторий станет приватным, все задания заблокируются до установки `ACTIONS_BUDGET_VERIFIED=true` после проверки включённой квоты и бюджета платного превышения $0 с остановкой. Переменная — ручной допуск, не автоматическая проверка биллинга. В CI нет реальных AI-вызовов. Статус выполнения проверок см. в PR; системный выбор фото дополнительно проверяется на Mac.
