# Saint Look

Цифровой гардероб и лукбуки: приложение помогает собирать образы из реальных вещей и оценивать покупки в контексте своего гардероба.

## Статус

Стадия идеи. Платформа, стек и объём MVP ещё не выбраны. Исходный контекст, продуктовые гипотезы и вопросы для обсуждения — в [lookbook-handoff.txt](lookbook-handoff.txt).

Следующий шаг: разобрать идею, выбрать минимальный эксперимент и только затем согласовать прототип и технический подход.

## Работа с Codex

Для проекта используется [Oh My Codex](https://github.com/Yeachan-Heo/oh-my-codex), версия `0.21.33`. Требуются Node.js 20+, npm и установленный, авторизованный Codex CLI.

Первичная настройка после клонирования:

```bash
npm install -g oh-my-codex@0.21.33
omx setup --scope project --merge-agents
omx doctor
```

Запуск из корня проекта:

```bash
omx
```

Локальные настройки `.codex/`, навыки `.agents/` и состояние `.omx/` исключены из Git. Проектные инструкции хранятся в `AGENTS.md`; исходный бриф сохраняется в репозитории.
