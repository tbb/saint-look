# Domain Docs

## Перед исследованием проекта

Используем single-context: один `GLOSSARY.md` в корне
и общие архитектурные решения в `docs/adr/`.

Прочитай словарь и ADR, относящиеся к текущей задаче.
Если файлов нет, продолжай без замечаний об их отсутствии.
Скилл domain-modeling создаёт их по мере согласования
терминов и решений.

## Термины

В задачах, предложениях, гипотезах и тестах используй термины
из словаря. Если нужного понятия нет, проверь, применяется ли
оно в проекте; реальный пробел отметь для domain-modeling.

## Архитектурные решения

Если предложение противоречит существующему ADR, явно укажи
это решение и причину, по которой его стоит пересмотреть.
