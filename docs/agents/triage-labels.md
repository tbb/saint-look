# Triage Labels

| Роль скилла | Лейбл в GitHub | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Нужна первичная оценка |
| needs-info | needs-info | Ждём уточнений от автора |
| ready-for-agent | ready-for-agent | Задача описана и готова к автономной работе агента |
| ready-for-human | ready-for-human | Требуется реализация человеком |
| wontfix | wontfix | Задача не будет выполняться |

Когда скилл называет роль, используй соответствующий лейбл
из этой таблицы. Для изменения словаря редактируй второй столбец.
