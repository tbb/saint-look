# Сохранение вещи при стилизации — #109

Проверка 2 ноября 2026 на трёх предоставленных владельцем фотографиях:
чёрная футболка с принтами, худи с золотым принтом, полосатые брюки.
Это измерение ограниченной выборки, а не гарантия качества для любого снимка.

## Причины и изменение

Заполненный шаблон навязывал стандартный узкий корпус. `silhouette=unknown`
в ответе JEV не означал, что вещь действительно узкая. Теперь одежда
редактируется по источнику, а шаблон задаёт допустимую область размещения.
Для измеримого корпуса численное отношение ширины к длине дополняет признаки.
Подол определяется по центральной части, отдельно от манжет; высота капюшона
не входит в длину корпуса. При посадке остаются только равномерный масштаб и
перенос: растягивание отдельных осей или штанин не исправляет результат.

Распознанные описания кроя убраны из инструкции редактирования: они не должны
заменять наблюдаемую форму стандартной «обычной длиной». Тип и цвета сохраняются,
полные признаки по-прежнему участвуют в регистрации и подготовленной версии.
Для белых и бежевых вещей используется серый фон генерации: на белом фоне
Photoroom ошибочно делал белую ткань полупрозрачной. Подготовленный оригинал
и его alpha не меняются.

Для обычного худи с длинными рукавами после исходников добавляется цель
редактирования: расправленная поза с измеренным корпусом, без дизайна вещи.
Она применяется только при измеримом отношении 0.4–1.0. Остальные длины и рукава
не получают эту геометрию. Один успешный результат не подтвердил повторяемость:
повтор41372728421 снова скопировал сложенные рукава и был отклонён.
Для остальных худи используется исходный фронтальный снимок и явное изменение
позы существующих рукавов с сохранением их фактической длины. Капюшон опущен; клиент помещает голову перед ним,
головной убор — перед головой. Крой и длина вещи не заменяются размерами тела.
Для брюк расширена допустимая область ширины при сохранении полной длины.

В каталог попадал весь холст из-за удалённых пикселей alpha=1. Миниатюра теперь
игнорирует этот уровень шума при выборе границ. Пиксели внутри границ и полный
холст примерочной сохраняются.

## Измерения и проверки

| Проверка | Результат |
| --- | --- |
| Прежняя футболка против исходника | Ширина/длина 0.593 против 0.779: около −24% |
| Раннее редактирование источника | 0.745: около −4%; отдельная экспериментальная инструкция |
| Футболка, два последовательных запуска полного адаптера | 0.747 и 0.738 против 0.784: −4.7% и −5.9%, допуск 8% |
| Худи с измеренным шаблоном позы | 0.873 против 0.884: −1.2%; рукава расправлены, капюшон опущен |
| Брюки через полный кандидатный адаптер | Полная длина и раздельные штанины; JEV подтвердил рисунок/материал с confidence 0.94 |
| Неподходящие повторные генерации | Зауженный корпус, сложенные/лишние рукава отклонялись до публикации |

Исходная методика использовала общий нижний край, включая манжеты. После
исправления на центральный подол исходное отношение футболки изменилось
0.779 → 0.784; поэтому ранние и последние значения нельзя сравнивать как
измерения абсолютно одинаковым алгоритмом.

Полные пробы: [футболка](https://github.com/tbb/saint-look/actions/runs/41371658853),
[повтор футболки](https://github.com/tbb/saint-look/actions/runs/41371872085),
[худи](https://github.com/tbb/saint-look/actions/runs/41372576603),
[брюки](https://github.com/tbb/saint-look/actions/runs/41372153143).
На дополнительном белом поло проверка JEV отклонила изменение признаков.
Повторные пробы не дают 100% принятия: успешная отдельная генерация не доказывает
устойчивость ко всем фото. Неудачная генерация сохраняет предыдущую подготовленную
версию, новая вещь остаётся неподготовленной. Платного автоматического повтора нет.

Нативный запуск41370322471 сохранил каталог и редактор, затем упал на ожидании
исчезновения кнопки закрытого редактора. Снимок подтверждает возвращение к
деталям лука; ожидание заменено на видимость кнопки редактирования в целевом
экране. Этот запуск не считается успешной полной визуальной приёмкой.

Нативные проверки crop, состояния и iPhone Release прошли
[в этом запуске](https://github.com/tbb/saint-look/actions/runs/41368793611).
Ранее тот же тест удалённых alpha=1 пикселей
[падал на старом коде](https://github.com/tbb/saint-look/actions/runs/41363394107).
Локальные тесты также воспроизводят ложную смену пропорций при распрямлении
манжет и опускании капюшона, подмену принта, поздний ответ после удаления и
рестарт между оплаченной финализацией и проверкой качества. Последний до
исправления вызывал финализацию дважды, после — один раз с теми же PNG-байтами.

## Ограничения

Численная проверка работает только для устойчивого видимого корпуса верхней
одежды. Для скрученных брюк и неоднозначных исходников она не выдаёт фиктивную
оценку. Семантическая проверка JEV отбраковывает уверенные изменения четырёх
групп признаков, но не гарантирует точную типографику, мелкие детали или текстуру
потёртого принта. Явная подмена герба была найдена с confidence 0.96; меньшие
изменения текстуры могут оставаться неуверенными и проходить проверку.

Результаты провайдеров не считаются готовыми только по HTTP 200. Один ответ
Gemini для брюк завершился `incomplete`; GET сохранённого interaction подтвердил
этот исход без нового POST. Завершённые ответы проверенных трёх вещей содержали
по одному изображению — гипотеза о выборе промежуточного кадра не подтвердилась.
Нормативный смысл `incomplete` описан в
[Gemini Interactions API](https://ai.google.dev/api/interactions-api).

Новая стадия `fidelity` требует дополнительный JEV-запрос и может увеличить время
обработки. Вырезка сохраняется до этой стадии атомарно; неизвестный исход запроса
не повторяется. Тестовые фото, промптовые прототипы и временный workflow вынесены
из релизного diff. Старые v2/v3 публикации и подготовленные исходники сохраняются.
