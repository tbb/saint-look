# Альтернативы Gemini для распознавания вещи

Проверено 25 октября 2026. Исследование по публичным первичным источникам; аккаунты не создавались, фотографии провайдерам не отправлялись. Это рекомендация для выбора, а не принятое изменение провайдера. Код, развёртывание и платный биллинг не менялись.

## Задача и рекомендация

Нужны пригодность фотографии одной вещи без человека, тип вещи и основные цвета на русском, структурированный ответ. Вырезка остаётся отдельной операцией. Первая проба — 2–3 подготовленных публичных фото, пользователь в Финляндии. Определение вещи — в [словаре](../../GLOSSARY.md); реальные запросы отделены от обычного CI по [ADR-0001](../adr/0001-shared-repository.md).

Предлагаем **Groq с `qwen/qwen3.8-27b` для бесплатной dev-пробы**. По документации совпадают необходимые возможности: изображения и строгая JSON Schema. Это выбор по удобству пробы и условиям данных, а не доказанное превосходство качества. Модель имеет статус Preview; закреплять её как постоянного production-провайдера сейчас не следует. [Vision](https://console.groq.com/docs/vision), [структурированные ответы](https://console.groq.com/docs/structured-outputs), [статусы моделей](https://console.groq.com/docs/models).

## Groq: лучший кандидат для первой бесплатной пробы

- `qwen/qwen3.8-27b` принимает изображения и поддерживает `json_schema` со `strict: true`. Для нашей короткой классификации можно отключить reasoning через `reasoning_effort: none`; серверная проверка suitability/type/colors всё равно необходима. [Vision](https://console.groq.com/docs/vision), [Schema](https://console.groq.com/docs/structured-outputs), [reasoning](https://console.groq.com/docs/reasoning).
- Публичная таблица Free Plan: 30 запросов/мин, 1 000/сутки, 8 000 токенов/мин и 200 000/сутки. Одна картинка — 2 048 входных токенов. Поэтому 1 000 запросов нельзя читать как 1 000 фото в день; токенный лимит сработает раньше. Фактическую квоту нужно подтвердить в кабинете; 2–3 запроса отправлять последовательно. [Лимиты](https://console.groq.com/docs/rate-limits), [изображения](https://console.groq.com/docs/vision).
- Платный Developer включается отдельным upgrade с платёжным методом. Для пробы оставляем Free. Платная цена модели $0.80 / $4.00 за миллион входных / выходных токенов; это не фиксированная цена фотографии. [Billing](https://console.groq.com/docs/billing-faqs), [модель](https://console.groq.com/docs/model/qwen/qwen3.8-27b).
- Groq не использует входы/выходы для обучения без явного разрешения. Для inference нет обычного сохранения содержимого, но возможны диагностические/abuse-логи до 30 дней; все клиенты могут включить Zero Data Retention в Data Controls. Служебные метаданные сохраняются. Страница указывает США для сохраняемых данных; обещать EU-only нельзя. [Данные](https://console.groq.com/docs/your-data), [Services Agreement, §4.2](https://console.groq.com/docs/legal/services-agreement).
- Preview предназначен для оценки и может быть быстро снят с обслуживания. Условия §3.6 также исключают Beta Services из DPA, если документация явно не устанавливает иное. Это ограничивает рекомендацию подготовленными публичными фото и dev-проверкой, а не запуском с пользовательскими персональными данными. [Модели](https://console.groq.com/docs/models), [Agreement](https://console.groq.com/docs/legal/services-agreement).
- Agreement предусматривает клиентов из ЕЭЗ и использование сервиса в клиентском приложении. Требования обязательно оплачивать сервис из-за ЕЭЗ в просмотренных условиях не обнаружено. Это основание выбрать кандидата для Финляндии, но не гарантия регистрации конкретного аккаунта. Доступность для РФ и всех стран СНГ не подтверждена. [Agreement](https://console.groq.com/docs/legal/services-agreement).

## Mistral: кандидат для постоянного использования

`ministral-8b-2512` (Ministral 3 8B) имеет статус GA, vision и structured outputs. Цена $0.15 за миллион входных и столько же за миллион выходных токенов. Это существенно дешевле платного Groq по токенным тарифам, но качество и фактический расход на наших фото ещё не сравнивались. [Карточка модели](https://docs.mistral.ai/models/ministral-3-8b-25-12).

Официальный quickstart описывает Free mode без карты; точную квоту модели нужно смотреть в Admin → Limits. Ненулевой доступ нового аккаунта в этом исследовании не подтверждён. Поэтому это второй кандидат для бесплатной пробы и перспективный кандидат для платного постоянного использования после согласования бюджета. [Активация](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key), [лимиты](https://help.mistral.ai/en/articles/698531-why-am-i-hitting-api-rate-limits-and-how-do-i-increase-them).

В бесплатном API данные могут использоваться для обучения; отдельный API opt-out доступен в Admin → Privacy → Anonymous improvement data. Он не равен ZDR: последний предоставляется только pay-as-you-go по запросу. Данные размещаются в EU по умолчанию, но есть исключения для отдельных функций/subprocessors. [Обучение](https://help.mistral.ai/en/articles/347617-do-you-use-my-user-data-to-train-your-artificial-intelligence-models), [API opt-out](https://help.mistral.ai/en/articles/455207-can-i-opt-out-of-my-input-or-output-data-being-used-for-training), [ZDR](https://help.mistral.ai/en/articles/347612-can-i-activate-zero-data-retention-zdr), [hosting](https://help.mistral.ai/en/articles/347629-where-do-you-store-my-data-or-my-organization-s-data).

Custom Structured Outputs принимает JSON Schema; это не доказательство точности распознавания и не повод убирать серверную проверку. Коммерческие условия описывают клиентские приложения, но поддержку РФ/всего СНГ отдельно не подтверждают. [Schema](https://docs.mistral.ai/studio/conversations/structured-output/custom), [Commercial Terms](https://legal.mistral.ai/terms/commercial-terms-of-service/).

## Alibaba Cloud Model Studio: запасной вариант

`qwen3-vl-plus`, Singapore / International: 1 млн токенов на 90 дней, платная цена при контексте до 32K — $0.20 / $1.60 за миллион входных / выходных токенов. Бесплатный остаток не означает остановку расходов: `Free Quota Only` по умолчанию выключен, включение применяется с задержкой. [Тарифы](https://www.alibabacloud.com/help/en/model-studio/model-pricing), [квота](https://www.alibabacloud.com/help/en/model-studio/new-free-quota).

Регистрация требует телефон, платёжный метод и billing address. Для мультимодальных запросов JSON Schema понижается до JSON Object; строгая структура не гарантируется. Это больше настройки ради нашей маленькой пробы. [Регистрация](https://www.alibabacloud.com/help/en/account/step-1-register-an-alibaba-cloud-account), [structured output](https://www.alibabacloud.com/help/en/model-studio/qwen-structured-output).

Без согласия данные не используются для развития моделей, но стандартное хранение запросов/ответов — до 30 дней с исключениями. ZDR требует enterprise-договора и поддержки конкретной модели. Географию аккаунта/конечных пользователей нужно проверять отдельно; Singapore как регион сервера не подтверждает поддержку РФ. [Условия Model Studio](https://www.alibabacloud.com/help/en/legal/latest/alibaba-cloud-international-website-product-terms-of-service-v-3-8-0), [retention](https://www.alibabacloud.com/help/en/model-studio/data-retention-policy).

## Другие проверенные варианты

**OpenRouter.** Бесплатные модели доступны с ограничениями, но сам сервис не рекомендует их для production. Политики хранения/обучения зависят от конечного поставщика модели. Для нашей первой пробы это добавляет ещё одного участника и необходимость закрепить конкретный маршрут; автоматический выбор случайной бесплатной модели не подходит для воспроизводимой проверки. [Поддержка](https://openrouter.ai/support), [данные](https://openrouter.ai/privacy).

**Cloudflare Workers AI.** Есть 10 000 бесплатных Neurons в день с остановкой на Free при исчерпании, no-training и отсутствие хранения содержимого стандартных запросов с оговорёнными исключениями. Но найденные схемы API не дают такого же однозначного совпадения vision + строгой структуры: Llama 3.2 Vision принимает изображения, а в её input schema нет параметра структурированного ответа; страница Mistral Small 3.1 описывает возможности базовой модели, но не показывает image input. Поэтому сейчас ниже Groq в списке, а не утверждение о невозможности интеграции. [Цена](https://developers.cloudflare.com/workers-ai/platform/pricing/), [данные](https://developers.cloudflare.com/workers-ai/platform/data-usage/), [Llama](https://developers.cloudflare.com/workers-ai/models/llama-3.2-11b-vision-instruct/), [Mistral](https://developers.cloudflare.com/workers-ai/models/mistral-small-3.1-24b-instruct/).

## Вырезка и следующий шаг

Photoroom оставляем кандидатом для вырезки: опубликованы 10 бесплатных production-вызовов Remove Background без watermark и без карты. Условия обучения/opt-out конкретного API Space ещё требуют проверки, как зафиксировано в [исследовании аккаунтов](provider-account-preflight.md). [Тариф и FAQ](https://www.photoroom.com/api/pricing).

После выбора пользователя: проверить доступ и Free-квоту аккаунта Groq, включить ZDR, подтвердить Photoroom-квоту/условия данных; затем заменить только адаптер атрибутов и связанные настройки ключа/проверки. Сохранить текущий контракт, асинхронную очередь, удаление и запрет автоматического повторения неизвестного результата. Исходный интерфейс — [providers.mjs](../../backend/src/providers.mjs).

При пробе фиксировать пригодность, тип, цвета, сохранность рисунка/контура вырезки и фактический расход. Успешные 2–3 фото подтверждают работу механизма; они не доказывают качество на всём гардеробе. Выбор модели для постоянного использования и подтверждение доступности РФ остаются отдельными решениями.

## Уточнение бюджета и роли Photoroom

После сравнения пользователь предложил бюджет $10 на 20–30 вещей, затем уточнил вместимость пакета Photoroom за $20 и назвал её приемлемой. Покупки и включение платных планов не выполнялись.

Photoroom Basic начинается от $20/месяц за 1 000 удалений фона. Остаток не переносится. Считать 30 фото как $0.60 фактического входного платежа нельзя: требуется весь месячный пакет. [Минимальный пакет](https://www.photoroom.com/api/startup-plan), [тарифы](https://www.photoroom.com/api/pricing).

Для жёсткого бюджета $10 на API запасной вариант вырезки — BRIA RMBG 2.0 через fal: $0.018 за изображение без дополнительного prompt, 30 вызовов стоят $0.54. Коммерческое использование отмечено на странице модели. Публичная инструкция fal указывает минимальное пополнение $1; фактическую сумму и налоги нужно проверить в checkout. [BRIA](https://fal.ai/models/fal-ai/bria/background/remove), [пополнение](https://fal.ai/learn/tools/how-to-generate-ai-videos-with-an-api).

fal API terms запрещают использовать Client Content для обучения, кроме специально обозначенных исключённых моделей; на странице BRIA соответствующей пометки не обнаружено. Обычная история запросов хранится 90 дней. Отключение истории через `X-Fal-Store-IO:0` не равно полному ZDR: CDN и технические логи регулируются отдельно. [API terms](https://fal.ai/legal/api-services), [retention](https://fal.ai/docs/documentation/model-apis/media-expiration).

Если месячный пакет $20 приемлем, рекомендуем сохранить Photoroom для вырезок и уже реализованный Gemini 3.1 Flash-Lite для пригодности/типа/цветов. Gemini Prepay требует от $5: стартовые пополнения составят от $25 до возможных налогов, хотя расход распознавания 30 вещей будет намного меньше. Минимальный платёж не равен стоимости обработки. На тарифе $0.25/M input и $1.50/M output условные 10 000 входных + 500 выходных токенов на фото дадут $0.0975 за 30 фото; это расчёт с допущением, не измерение. [Gemini billing](https://ai.google.dev/gemini-api/docs/billing), [тариф модели](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite).

В нашем направлении Photoroom готовит изображение вещи; структурированные признаки, векторы, сочетаемость и подбор комплектов остаются отдельными задачами. Коллаж из готовых вырезок можно собирать на клиенте без нового вызова Photoroom. Это архитектурная рекомендация по [направлению продукта](../decision-ai-at-ingestion.md), а не утверждение о готовом подборе. Более сложное редактирование изображений Photoroom доступно в Image Editing API по $0.10 за вызов; при использовании Basic оно расходует пять единиц вместо одной. [Image Editing pricing](https://docs.photoroom.com/image-editing-api-plus-plan/pricing.md), [учёт вызовов](https://docs.photoroom.com/getting-started/pricing).

## Уточнение: Jev и будущий подбор

Пользователь подтвердил Photoroom для вырезки, предложил Jev для распознавания и эмбеддинги с возможной асинхронной оценкой LLM для подбора. Jev ещё не выбран вместо Gemini и не подключён; отдельная проверка записана в `jev-for-wardrobe.md`.

Предлагаем для этапа подбора: вычислять эмбеддинг изображения один раз при добавлении/замене фото; выбирать кандидатов с учётом типа и нужного места в комплекте; асинхронно оценивать небольшой набор полных комплектов и сохранять результат. При ручном изменении признаков пересматривать только зависимые оценки, а при удалении исключать вещь из сохранённых комплектов. Готовые результаты показывать без нового вызова модели при каждом открытии.

Обычная визуальная близость не определяет сочетаемость: похожая рубашка может быть альтернативой другой рубашке, а брюки, которые подходят к ней, выглядят иначе. В специализированных исследованиях сходство и совместимость обучают как разные отношения с учётом типа вещи. [Learning Type-Aware Embeddings for Fashion Compatibility](https://arxiv.org/abs/1803.09196).

Для 20–30 вещей отдельная векторная БД не требуется: достаточно хранить векторы рядом с карточками и считать сходство в приложении. Это предложение реализации, а не выбранная embedding-модель. Отдельная LLM или Jev может оценивать кандидатов, но полезность нужно проверить на комплектах пользователя; вероятности модели сами по себе не являются измеренной уверенностью в его вкусах. Первый этап фото → карточка не расширяется подбором автоматически.
