# Аккаунты для первой пробы Photoroom и Gemini

Проверено 25 октября 2026 по официальным источникам. Это подготовка #10: 2–3 публичных фото одной вещи без человека, без платного перехода. Аккаунты, ключи и фактические остатки квот пользователя не проверялись; регистраций и вызовов обработки в рамках исследования не было. Решения проекта — в [уточнениях первого этапа](../decision-ai-at-ingestion.md#первый-этап-уточнения-от-24-октября-2026).

## Photoroom: публичные условия

Новый аккаунт получает 10 бесплатных production-вызовов Remove Background API без водяного знака; карта для пробы не нужна. Отдельные 1 000 sandbox-вызовов Image Editing API в месяц дают watermark и не заменяют выбранную пробу. Переход на платный Basic/Plus оформляется в API dashboard; наличие бесплатного предложения не подтверждает остаток конкретного аккаунта. [Тарифы и FAQ](https://www.photoroom.com/api/pricing).

В [Web App](https://app.photoroom.com/api-dashboard) администратор выбирает Space и включает API через `Enable the Photoroom API for free`. Затем `API dashboard → API keys` показывает отдельные Live и Sandbox keys. Для выбранной пробы нужен Live key. Это API-настройка Space, а не покупка мобильной подписки. [Включение API](https://help.photoroom.com/en/articles/15419402-enable-the-photoroom-api-web-app), [получение ключей](https://help.photoroom.com/en/articles/15419535-find-your-photoroom-api-keys-web-app), [независимость API-подписки](https://docs.photoroom.com/getting-started/pricing).

Остаток и историю расхода показывает API dashboard; документация также описывает `GET https://image-api.photoroom.com/v2/account` с `x-api-key` и полями `images.available`, `images.subscription`, `plan`. Этот запрос здесь не выполнялся. [Учёт квоты](https://docs.photoroom.com/getting-started/pricing). Вывод для нашей проверки: клиентский таймаут нельзя приравнивать к подтверждённой ошибке обработки у провайдера и гарантированно бесплатному вызову.

По обучению источники расходятся: текущая security-страница указывает обучение для self-serve API по умолчанию и opt-out в settings; Help Center от 20 октября 2025 утверждает, что API-фото не используются для обучения без отдельного запроса. Security-страница прямо отделяет app opt-out от API-условий. Поэтому переключатель приложения `Improve model for everyone` сам по себе не подтверждает API opt-out. Точный путь и название API-переключателя открытые страницы не устанавливают — нужно проверить применимые настройки API Space/условия аккаунта; если их нет, выяснить у поддержки до отправки фото. [Security](https://www.photoroom.com/platform/security), [Help Center: данные](https://help.photoroom.com/en/articles/8707489-permission-for-photoroom-to-use-your-data), [Help Center: обучение](https://help.photoroom.com/en/articles/10067660-does-the-ai-learn-from-your-images).

## Gemini: публичные условия

Стабильный идентификатор `gemini-3.1-flash-lite` поддерживает изображения и структурированный ответ. Standard Free Tier включает бесплатные входные и выходные токены. Это подтверждает выбор модели, но не доступ и квоту проекта. [Модель](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite), [тариф](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite).

Ключ создаётся в [Google AI Studio](https://aistudio.google.com/apikey) и связан с Cloud project. Для новых пользователей после принятия условий автоматически создаются проект и ключ; существующий проект может потребовать импорта. Новые ключи AI Studio с 28 мая 2026 создаются как authorization keys; старые unrestricted standard keys отклоняются. [Инструкция по ключам](https://ai.google.dev/gemini-api/docs/api-key).

Фактический Free Tier проверяется в Projects; переход на платный требует настройки billing. Ключ наследует биллинг проекта: новый ключ в уже платном проекте не делает запросы бесплатными. Актуальные лимиты модели смотрят в AI Studio, они применяются к проекту и не гарантируются публичной таблицей. [Billing](https://ai.google.dev/gemini-api/docs/billing), [лимиты](https://ai.google.dev/gemini-api/docs/rate-limits).

Доступ зависит от [поддерживаемого региона](https://ai.google.dev/gemini-api/docs/available-regions) и требований аккаунта. Нидерланды в списке есть; это не доказательство доступности аккаунта пользователя только потому, что Fly работает в AMS. Условия Google отдельно требуют Paid Services при предоставлении API Clients пользователям в EEA, Швейцарии и Великобритании; применимость к выбранной демонстрации нужно проверить до включения live, не подключая billing автоматически. [Условия, Use Restrictions](https://ai.google.dev/gemini-api/terms).

Для Unpaid Services условия допускают использование входа/выхода для улучшения моделей и человеческий просмотр; запрещают отправку чувствительных, конфиденциальных и личных данных. Для EEA/Швейцарии/Великобритании предусмотрено отдельное правило обработки данных. В рамках проекта сохраняем согласованное ограничение публичными тестовыми фото. [Условия, Unpaid Services](https://ai.google.dev/gemini-api/terms).

## Что проверить в аккаунтах перед запуском

- Photoroom: выбран правильный Space, Live key, остаток production Remove Background квоты достаточен для 2–3 снимков; API opt-out подтверждён; платный план не включён.
- Gemini: выбран правильный Cloud project с Free Tier, модель доступна, текущие лимиты достаточны; регион и условия выбранного сценария проверены.
- Для каждого фото известны публичный источник и право использования; ключи передаются только через защищённую настройку backend, не через чат, клиент или репозиторий.
- Перед и после пробы записываются время, модель, фактический расход и результат без секретов. Если бесплатная квота недоступна, платный переход не выполняется автоматически.

Это проверки проекта по согласованной спецификации, а не утверждения о текущем состоянии пользовательских аккаунтов.
