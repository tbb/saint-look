# Альтернативы Railway для dev-стенда

Проверено 24 октября 2026. Это исследование вариантов, не решение о миграции и не подтверждение доступности конкретного аккаунта. Ресурсы не создавались. Основание: новые регистрации Railway приостановлены; [официальное уведомление](https://status.railway.com/incident/ZEO9X68O).

Нужны один Docker backend с фоновой обработкой, SQLite и временными результатами на постоянном диске, HTTPS, секреты, ручная выкладка проверенного SHA и откат кода с текущими данными. Небольшой простой допустим. ADR-0002 предусматривает бюджет около $10/месяц отдельно от AI API, уведомления и остановку по лимиту, отсутствие резервных копий временных данных.

| Вариант | Ориентир стоимости | Что подходит | Существенное ограничение |
| --- | --- | --- | --- |
| Fly.io Machines | Примерно $7–9/месяц за одну небольшую машину с 1 GB RAM и диском 3 GB, до налогов и трафика | Docker, постоянный volume, отключаемые scheduled snapshots; близко к управляемому Railway | Нет встроенных billing alerts; жёсткий общий предел счёта не подтверждён |
| Render | $7 за 512 MB web service + $0.25/GB диска; 3 GB дают $7.75/месяц до доплат | Один платный web service может запускать наш API и встроенный worker; диск переживает redeploy | Ежедневные snapshots на 7 дней; возможность отключить их не найдена в документации |
| DigitalOcean Basic Droplet | $6/месяц: 1 GiB RAM, 1 vCPU, SSD 25 GiB, 1000 GiB исходящего трафика, IPv4 | Постоянный локальный диск, Docker, можно не включать backups; предсказуемая цена одной VM | Это VPS: ОС, Docker, HTTPS и эксплуатация остаются у нас; alerts не останавливают Droplet |

## Fly.io

По текущей [странице цен](https://fly.io/pricing/) shared-1x 256 MB стоит $2.19/месяц, дополнительная RAM — $6/GB-месяц, volume — $0.15/GB-месяц. Расчёт для 1 GB RAM и диска 3 GB: $2.19 + 0.75 × $6 + 3 × $0.15 ≈ **$7.14**, без исходящего трафика и налогов. Цены зависят от региона; отдельные страницы документации показывают отличающиеся суммы, поэтому это ориентир, который надо сверить в выбранном регионе перед созданием. Выделенный IPv4 необязателен: есть shared IPv4. [Тарифы](https://fly.io/pricing/).

Scheduled snapshots можно выключить через `--scheduled-snapshots=false`; volume хранится отдельно от эфемерной файловой системы машины. Это позволяет сохранить правило об отсутствии резервных копий. [Управление volumes](https://docs.fly.io/volumes/volume-manage).

Fly прямо сообщает об отсутствии billing alerts; allowance не ограничивает счёт, volume оплачивается и при остановленной машине. Поэтому соответствие требованию ADR об автоматической остановке по общему бюджету **не доказано**. Для нашего worker предлагается одна постоянно работающая машина без autoscaling; это проектное предложение, а не измерение необходимой RAM. [Управление расходами](https://docs.fly.io/about/cost-management).

## Render

Hobby workspace без отдельной платы; минимальный платный web service 512 MB — $7/месяц, persistent disk — $0.25/GB. Включено 5 GB исходящего трафика, далее $0.15/GB. Отдельный оплачиваемый background worker нашей текущей архитектуре не нужен: worker уже находится в backend. [Цены](https://render.com/pricing?trk=article-ssr-frontend-pulse_little-text-block).

Диск привязан к одному экземпляру, переживает перезапуски и выкладки; redeploy даёт небольшой простой. Render автоматически сохраняет ежедневные snapshots на 7 дней. Документированного отключения не найдено: до подтверждения поддержкой либо явного пересмотра требования Render не проходит условие «без backups». [Диски](https://render.com/docs/disks).

Лимит расходов на build pipeline ограничивает сборки, а не весь счёт; при добавленной карте исходящий трафик сверх включённого оплачивается. Нельзя называть $7.75 жёстким потолком. [FAQ](https://render.com/docs/faq), [pipeline budget](https://render.com/docs/build-pipeline).

## DigitalOcean Droplet

Проверенный вариант — **Basic Regular bundled 1 GiB за $6**, не v5 с оплатой конфигурируемых ресурсов. В базовую цену входят SSD и IPv4; отдельный volume для этого dev-стенда не требуется. RAM нужно проверить на нашем контейнере, достаточность 1 GiB пока является оценкой. [Тарифы](https://www.digitalocean.com/pricing/droplets).

У bundled Droplet есть месячный предел стоимости самой VM, но остановка питания не прекращает её тарификацию. Общий счёт дополнительно зависит от налогов и услуг; сверх включённого трафика — $0.01/GiB. [Правила тарификации](https://docs.digitalocean.com/products/droplets/details/pricing/), [bandwidth](https://docs.digitalocean.com/platform/billing/bandwidth/).

Backups можно отключить, а при создании стенда вообще не включать; имеющиеся копии после отключения сохраняются до планового удаления. [Отключение backups](https://docs.digitalocean.com/products/backups/how-to/disable/). Spend alerts доступны, но **не являются spending cap**: для Droplets автоматической остановки по бюджету эта функция не предоставляет. [Spend alerts](https://docs.digitalocean.com/platform/billing/spend-alerts/).

## Вывод и объём переноса

Предварительно **Fly.io** ближе к исходному выбору управляемой платформы и позволяет выключить snapshots. **DigitalOcean за $6** — альтернатива с понятной ценой VM, если принимаем обслуживание VPS. Render стоит рассматривать после разрешения вопроса с обязательными snapshots. Ни один из этих вариантов пока не подтверждён как полное выполнение ADR-0002 по автоматическому ограничению общего счёта; это решение нельзя незаметно ослабить при переносе.

Продуктовая логика backend и iOS сохраняется. Меняются конфигурация хостинга, upload/deploy часть GitHub Actions, выдача идентификатора конкретного запуска и секреты. Проверки точного SHA, чистый release archive, API/Simulator smoke и совместимость SQLite можно использовать повторно. Для VPS дополнительно нужны установка/обновление ОС и Docker, firewall, HTTPS, запуск после reboot и деплой образа вместо пересоздания диска. Любой выбор потребует обновить ADR-0002 и выполнить реальные проверки restart/redeploy/rollback с сохранением очереди и результатов.
