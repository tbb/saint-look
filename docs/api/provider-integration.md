# Протоколы провайдеров первого этапа

Реализация #3 и серверной части #4 использует два последовательных этапа. Документация проверена 24 октября 2026; доступность конкретных аккаунтов не проверялась, настоящие API не вызывались.

Сначала `POST https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-lite:generateContent` с ключом в `x-goog-api-key`, нормализованным PNG в `contents[].parts[].inlineData` и JSON schema в `generationConfig.responseJsonSchema`. Модель возвращает `suitable`, безопасную категорию причины отказа, `type` и `colors`; проверяются окончание ответа, форма и непустые ограниченные строки. Structured output не заменяет серверную валидацию. Используется стабильная текстовая мультимодальная модель, не модель генерации изображений. [Модель](https://ai.google.dev/gemini-api/docs/models/gemini-3.1-flash-lite), [REST API](https://ai.google.dev/api/generate-content).

Затем `POST https://sdk.photoroom.com/v1/segment` с `x-api-key` и multipart-полями `image_file`, `format=png`, `despill=false`. Этот API удаляет фон без генеративной перерисовки; отключение despill сохраняет исходные цвета. PNG проверяется на размер, декодируемость, прозрачность и наличие видимых пикселей, лишние метаданные удаляются. Проверка не доказывает качество сегментации: для этого нужна отдельная визуальная проба. [Quickstart и ограничение изменения пикселей](https://docs.photoroom.com/remove-background-api-basic-plan/quickstart-guide), [параметры API](https://docs.photoroom.com/getting-started/api-reference-openapi), [despill](https://docs.photoroom.com/remove-background-api-basic-plan/green-screen-despill).

Ни SDK с автоматическими повторами, ни переключение модели/тарифа не используются. HTTP 401/403 — `provider_unauthorized`, 402/429 — `provider_quota_exceeded`, другие 4xx — `provider_rejected`. 5xx, потерянный ответ и таймаут трактуются консервативно как `processing_unknown`: провайдер мог принять запрос и списать квоту. Это также относится к прерыванию процесса между записью намерения и записью результата. Автоматического повтора такого этапа нет. Сырые тела ошибок, ключи и содержимое фото не попадают в ответы API и логи.

Перед реальной пробой нужны ручные проверки аккаунтов, бесплатных квот и opt-out Photoroom. Photoroom описывает 10 пробных production-вызовов удаления фона для нового аккаунта, но остаток конкретного аккаунта надо проверить отдельно. Self-serve API использует фото для обучения по умолчанию; opt-out находится в настройках. Gemini имеет отдельные бесплатные и платные условия, а доступность и лимиты зависят от аккаунта. Флаг `SAINT_LOOK_PROVIDER_PREFLIGHT_CONFIRMED` — подтверждение оператора, а не средство проверки биллинга. [Photoroom pricing](https://www.photoroom.com/api/pricing), [Photoroom privacy](https://www.photoroom.com/platform/security), [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite).
