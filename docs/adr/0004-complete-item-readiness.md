# Единая готовность вещи для использования в луках

29 октября 2026 согласована единая готовность: вещь доступна ручному конструктору
и автоматическому подбору только после полного завершения пайплайна изображения
и всех необходимых обработок, включая эмбеддинги. Готовая картинка при ещё
незавершённой подготовке представлений не даёт частичного допуска к лукам.

Предложение разрешать ручное использование раньше автоматического отклонено:
пользователь выбрал одно понятное состояние готовности. Цена этого решения —
новая вещь может ждать завершения последнего этапа перед любым использованием
в луках. Эмбеддинги допустимо вычислять раньше иллюстрации или параллельно ей;
решение не требует последовательного исполнения всех этапов.

При обновлении признаков или модели последняя полностью готовая версия продолжает
использоваться в луках до завершения новой. Новая версия публикуется целиком:
изображение, признаки и эмбеддинги согласованы между собой. Ошибка новой обработки
не лишает пользователя предыдущей готовой версии; новые изменения начинают
участвовать в луках только после полной готовности. У новой вещи без готовой
версии допуска к лукам нет. Пересчитываются зависимые данные; повторно запускать
неизменившиеся платные этапы это решение не требует.

При декомпозиции #63 пользователь уточнил: после полной готовности фиксируется
весь набор исходных фотографий. Замена основного снимка и добавление/изменение
ракурсов после готовности в MVP не поддерживаются. До первой полной готовности
неудачный снимок можно исправить. Другая фотография подготовленной вещи означает
добавление новой вещи с новым ID; удаление старой не переносит ссылки луков
автоматически. Новые локальные/серверные валидации фото и дальнейшая работа с
ракурсами обсуждаются отдельно. Это уточнение заменяет раннее разрешение
обновлять исходное фото уже подготовленной вещи, но сохраняет обновление
производных результатов при правке признаков или смене модели.
