# Автоматический подбор луков на сервере

29 октября 2026 для первой интеграции подбора согласовано серверное выполнение:
автоматические рекомендации требуют сети, а просмотр локального гардероба,
сохранённые луки и ручной конструктор остаются доступны без неё. Это позволяет
менять модель, включая дообученные варианты, без обновления iOS-приложения.

Граница рекомендателя должна отделять модель от продуктовых правил мест,
слоёв, закреплений и исключений. Первый кандидат — OutfitTransformer-LaBSE;
его выбор не означает подтверждённое качество или пригодность текущей Fly-машины.

Постоянное серверное хранение и восстановление гардероба согласованы как отдельная
будущая задача вне эпика #63. Регистрация и новая система авторизации отложены.
Серверный подбор не должен зависеть от реализации этого облачного каталога;
конкретная инфраструктура ещё не выбрана. В #63 сохраняются правила временного
хранения из [ADR-0002](0002-managed-dev-hosting.md).
